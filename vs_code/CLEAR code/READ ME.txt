First the requirements is that you use blocks or python a C++ version may be made later. You will also need an Sd card a size of 2GB or bigger is recommended.
Next from this folder go to 2CLEAR then src there you will find CLEAR.py copy it and put it into the Sd card.
Then in the code you want to use the code with, if it is python put the code under "CODE:" if you are using blocks get a when started then in a switch block put in the code in "CODE:"
